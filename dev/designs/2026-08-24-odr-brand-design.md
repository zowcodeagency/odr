# Odr Brand and Marketing Design

## Objective

Create a memorable customer-facing identity and sales package for Odr, a calm,
minimal restaurant operating system for independent restaurants in India and
the Middle East.

## Brand idea

**Service Loop:** every order follows one clear path from table to kitchen to
bill. The mark is an open circular route with a forward signal, designed to
remain recognizable on a phone icon, a table QR card, a receipt, or signage.

The primary name is **odr**. Odr logo files do not carry a parent endorsement.
The supplied Zowcode mark may appear quietly on supporting corporate material,
such as the product overview back cover.

## Positioning

**Promise:** Run every table, order, kitchen ticket, and bill from one calm
system.

**Audience:** owner-operated restaurants with one to three outlets, from small
cafes and quick-service counters to full-service dining rooms.

**Personality:** fast, warm, dependable, uncomplicated, and modern.

**Competitive posture:** Odr is not presented as a feature-heavy replacement.
It is the focused alternative that keeps the daily restaurant workflow clear.

## Visual system

| Token | Value | Use |
|---|---:|---|
| Zowcode Green | `#40D39A` | Primary mark, calls to action, order motion |
| Deep Ink | `#111713` | Headlines, dark backgrounds, operational confidence |
| Cool White | `#F7FAF8` | Primary light background |
| Light Mint | `#78E8BF` | Supporting highlights on dark surfaces |
| Forest | `#087A52` | Positive status and supporting accents |
| Soft Sage | `#E5EDE9` | Dividers and secondary surfaces |

Use large lowercase wordmarks, generous whitespace, rounded geometry, and
short direct copy. Avoid food clip-art, gradients in the master logo, generic
fork-and-spoon symbols, decorative patterns, and crowded feature grids.

## Logo system

- Primary horizontal logo: Service Loop mark + lowercase `odr`, without a
  parent endorsement.
- Standalone mark: for app icons, favicons, QR table cards, avatars, and KOT
  headers.
- Reversed logo: cream on Deep Ink.
- Monochrome logo: one-color black/white reproduction.
- Clear space: at least half the mark diameter on every side.
- Minimum sizes: 24 px standalone mark; 96 px horizontal digital wordmark.

## Poster set

1. **Every order, one clear flow** - table to captain/QR to kitchen to bill.
2. **Built for the whole restaurant** - captain ordering, KOT/KDS, table
   tracking, GST/VAT invoices, menu control, and daily sales.
3. **Start small. Run big.** - a simple adoption message for independent
   restaurants, with fast menu onboarding and support for any outlet size.

The posters use A3 portrait proportions and remain readable from a distance.
Each poster has one headline, one visual idea, no more than six supporting
points, and one concise call to action.

## Product PDF

The product overview is a concise landscape document with these sections:

1. Brand promise and category.
2. The restaurant operating problem.
3. One connected order flow.
4. Captain and cashier workflow.
5. Kitchen workflow with KOT or KDS.
6. Menu, tables, QR ordering, and staff validation.
7. Billing, GST/VAT invoices, printing, and sales visibility.
8. Fit for small and growing restaurants.
9. Current versus planned capabilities.
10. Closing proposition and contact-ready back cover.

No payment gateway is claimed. Table QR ordering is presented as a unique QR
per table that opens the live menu, places the order into a staff-confirmation
queue, then joins the same KOT and running bill. Planned features are clearly
marked so the document never overstates the shipped product.

## Production requirements

- Keep all generated files under `dev/designs`.
- Preserve source files alongside final exports.
- Use deterministic vector/layout code for crisp output and repeatable builds.
- Use the supplied Zowcode logo only on supporting corporate material, not
  inside the Odr logo system.
- Verify every PDF by rendering all pages to PNG and visually checking them.
- Do not modify application code or unrelated working-tree files.
